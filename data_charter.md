# Data Charter — Reproducibility Bundle v5.0

**Manuscript.** *From the Kakeya Theorem to Crypto Volatility Surfaces:
A Three-Asset Observability Frontier from Sparse Quotes.*
Target: Nature (initial submission).
Snapshot freeze date: 2026-08-07.
Charter version: v5.0 (2026-08-17).

This charter classifies every empirical claim in the manuscript into
one of three data levels. The classification is binding: any table,
figure, or numerical statement in `manuscript/main.tex` carries
the level of its underlying source. Level-3 items are explicitly
flagged as *grounded simulations* in the manuscript body; the v3.0
manuscript contains **no L3 item**, and no headline result in any
version depends on L3.

## Level Definitions

| Level | Definition | Manuscript treatment |
|---|---|---|
| **L1 REAL** | Direct measurement from a public, verifiable API. Every raw row lives in `../datawang/` and hashes to `MANIFEST.json`. | No caveat. |
| **L2 PROXY** | A verifiable intermediate quantity is used as a proxy for an unobservable object of interest. The identification maps proxy → target explicitly, and a sensitivity check is provided. | Body labels the object as *proxy* and cites the sensitivity table. |
| **L3 SIM-GROUNDED** | No real data are available for the object of interest, but its distribution is disciplined by real-data priors and calibrated to match observed marginals. Never used to support a headline claim; only used for benchmarking. | Body labels the object *grounded simulation* and states what real data would be required to replace it. |

## Red Lines

1. **No fabrication.** No number in the manuscript is invented; every
   number is either measured (L1) or proxied (L2). The v3.0 manuscript
   contains no L3 item.
2. **No paywalled data.** SWIFT, BankFocus, Preqin, or any paid
   database is not used.
3. **L3 items never support the paper's headline results.** In v3.0
   there are no L3 items, so this rule holds vacuously; the rule
   remains in force for any future addition.
4. **Randomness is confined to statistical inference.** Every call to
   `numpy.random` in the analysis scripts is bound to the reproducible
   seed `20260814` and used exclusively for (i) block-bootstrap /
   pairs-bootstrap confidence intervals on real events, or (ii)
   five-fold cross-validation splits on real quotes. No data point in
   any table or figure is generated by random draw.
5. **Snapshot freeze.** All L1 quantities are frozen at 2026-08-07;
   any post-freeze update requires a new version bundle.

## Reproducibility

Every table and figure in the manuscript is regenerated by `make all`
in this bundle. See `README.md`. Total bundle footprint 13.07 MB
across 46 raw files from six independent public endpoints (Deribit,
Bybit, OKX, Dune Analytics, Binance, CoinGecko), hashed in
`MANIFEST.json`.
